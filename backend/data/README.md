# Bengaluru ward boundaries

`gba-wards.json` contains the final 369 Greater Bengaluru Authority ward polygons, with coordinates rounded to five decimal places for routing. The source data is attributed to the Greater Bengaluru Authority and published through [OpenCity's GBA ward delimitation dataset](https://data.opencity.in/dataset/gba-wards-delimitation-2025), under the Open Database License (ODbL 1.0). The public map and source description are also available through the [GBA delimitation portal](https://bbmp.gov.in/gba-corporations-delimitation-2025/index.html).

Ward matching is best-effort near boundaries. Civicloop shows the selected ward and corporation for review; verified ward contacts must be configured separately in `AUTHORITY_EMAILS_JSON`.
